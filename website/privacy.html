Privacy

This covers the Dune Legacy and Dune City games on every platform (Windows, macOS, Linux, the browser version, Android, iPhone and iPad) and this website. The games have no accounts, no advertising and no tracking across other apps or websites, and nothing is sold.

On your device

Settings, saved games, replays, downloaded maps and mods, and log files are stored on your device only. On iPhone and iPad they are in the Dune City folder in the Files app.

Match reports

When a new game starts and when it ends, the game sends a short report to dunelegacy.com: the game version and platform, the game mode, map and mod, the houses, AI opponents and their difficulty, the in-game player names, the result and how long the game lasted. In multiplayer games only the host sends it. The report contains no device identifier, account, contact details or location, and dunelegacy.com does not store the IP address it came from. Reports are used for the public usage statistics and to improve the game and its AI.

Online multiplayer

Hosting an internet game lists it on the dunelegacy.com game server with your public IP address, port, game name, map, mod and player count, so that other players can join. The listing disappears within a minute after the game stops being hosted. Players in the same game exchange game traffic directly or through the dunelegacy.com relay, which counts players joining and leaving a room by platform and game version.

Feedback

Feedback sent from inside the game is published as a public issue on the game's GitHub issue tracker with the title, description and game details you send. The server keeps a one-way hash of your IP address to enforce an hourly submission limit; the address is never attached to the issue.

This website

dunelegacy.com uses Google Analytics to count visits to its pages, which sets cookies in your browser. The games themselves do not use Google Analytics.

Questions

Ask about privacy or request removal of something you submitted by opening an issue on GitHub.
