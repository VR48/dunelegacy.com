New in 1.0.737: Browser matchmaking is available through Play Online → Find Match. Campaign games start online and public by default, with Private and Offline options, and hosts can start solo while friends join later. Desktop editions check for updates on launch; macOS, Windows installer and Linux AppImage users can install future updates from the main menu.
