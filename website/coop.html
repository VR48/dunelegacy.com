MULTIPLAYER CO-OP

Two commanders. One house.

Share a base, an army and a treasury. Build your colony while a friend leads the attack, or bring a QuantBot partner. Play a campaign together, carry on to the next mission, and save your progress for another session.

How to Host Join a Friend

Build requirement

Shared-house co-op requires desktop 1.0.652 or later on both computers. It has been tested through two campaign missions, including saving and reloading. Multiplayer co-op is available now in desktop 1.0.653 for Windows, macOS and Linux.

Download the latest desktop release. This guide covers the desktop game, not the browser or Android editions.

Share control

Both players command the same house, with shared units, buildings and credits. Agree who handles construction and who handles combat.

Human or QuantBot

Open the second controller slot for a friend, or select QuantBot Easy, Medium, Hard, Brutal or Defend.

Keep your progress

Campaign partners continue to the next mission together. Host a saved campaign when you want to pick up where you left off.

FOR THE HOST

Start a campaign together

  1. Open Host Campaign Co-op

    From Modes → Multiplayer, enter your player name and choose Host Campaign Co-op. You can also open Single Player → Campaign and choose Host Co-op on the house-selection screen.

  2. Choose your campaign

    Pick your house and starting mission, set the enemy AI difficulty, and adjust Game Options if needed. Leave the network choice on Internet to publish the lobby in Internet Games. Choose LAN only for a local-network session.

  3. Open the lobby

    Choose Host Co-op. Your name occupies Player 1. Leave Player 2 as Open human co-op for your friend, or choose a QuantBot partner. Both controller slots belong to your selected house.

  4. Start when your partner is ready

    Wait for your friend's name to appear in Player 2, then choose Next. The game checks the players' versions and mod settings before the countdown and shared mission begin.

FOR THE SECOND PLAYER

Join your friend's house

  1. Use the same build and mod

    Install the same desktop version as the host and select the same mod in Modes → Mods. For a Dune City campaign, both players should use Dune City.

  2. Find the lobby

    Go to Modes → Multiplayer, enter your own player name, then select Internet Games. Select your friend's campaign lobby and choose Join. Use LAN Games if the host chose LAN only.

  3. Check your shared house

    Your name should appear beside the host under the same house. Wait for the host to choose Next. Both players load the same mission and can control the house together.

Just one mission? Host a skirmish.

Open Modes → Single Player → Skirmish, choose the house and mission, select Internet or LAN only, then choose Host Co-op. The same shared-house lobby and joining steps apply. Skirmish plays the selected mission; choose campaign co-op to progress from one mission to the next.

Host Internet Custom Game in Multiplayer remains the route for a custom-map lobby.

Save, reload and continue

Use Options → Save Game during play. To resume together, return to Multiplayer → Host Campaign Co-op and choose the appropriate load button:

Load Co-op Save

Resume a campaign saved during shared play. Choose the file, open the lobby, and let your partner join again before selecting Next.

Load Campaign Save

Turn an existing single-player campaign save into a co-op session. Choose the save, then open the second slot for a human or QuantBot.

The player hosting the resumed session needs the save file. After a campaign victory, the host selects the next mission and both players continue with their shared house.

If you cannot find or join a game

The lobby is missing

Check that the host has opened the lobby with Internet selected and that the guest is viewing Internet Games. Give the list a moment to refresh. A LAN-only game appears in LAN Games instead.

The game reports a version or mod mismatch

Use the same desktop release and mod on both computers. Match any custom mod settings or files too, then rejoin the lobby.

The lobby appears, but the connection fails

Allow the game through your firewall. Internet hosting attempts automatic router setup and NAT traversal; some networks still require UDP forwarding for the host's configured server port (28747 by default).
